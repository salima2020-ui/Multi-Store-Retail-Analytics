# Multi-Store Retail Sales Analysis


This project is an end-to-end exploratory data analysis of weekly sales across a multi-store retail chain. The goal is to understand which stores drive revenue, how sales evolve over time, and whether external economic conditions influence customer spending.

The analysis answers five business questions:

- Which stores perform best, and how do they group into performance tiers (Top 10, Mid 25, Bottom 10)?
- How do total sales change month by month?
- How fast is each store growing year over year?
- How strongly do temperature, fuel price, CPI and unemployment correlate with weekly sales?
- Which individual stores are most sensitive to changes in unemployment?

Calculations are performed with pandas, and the findings are presented through matplotlib charts, so that store managers and analysts can quickly see patterns and prioritize where to act.

## Technologies Used

- **Python 3**: programming language
- **Google Colab**: cloud notebook environment to run the code
- **pandas**: data loading, grouping, aggregation, pivot tables, ranking, correlation calculations
- **matplotlib**: bar, line and heatmap visualizations
